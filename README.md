## 一、平台定位

面向**应用型本科会计类专业**的《民用航空运输企业会计》课程配套智能学习系统。将分散的知识点、习题、案例与智能辅导整合为统一界面，支持「看图谱 → 学知识点 → 做练习 → 问智能体」的闭环学习路径。

- **去学校化 · 通用化**：内容不绑定特定院校，可直接迁移到任意同类课程。
- **零部署**：纯静态托管（GitHub Pages），打开网址即用，无需安装、无需服务器。
- **离线可用**：数据打包进 `data.bundle.js`，RAG 推理在浏览器本地完成，断网也能查。

## 六、技术架构

```
index.html        ← 单页应用（UI + 渲染逻辑）
data.bundle.js    ← 课程数据（window.APP_DATA，1.3MB）
rag-client.js     ← 浏览器端 RAG 镜像（中文 lexical 检索 + 来源优先级）
.nojekyll         ← 关闭 Jekyll 处理
```

- **纯客户端**：所有推理在浏览器完成，无任何后端 API 依赖。
- **数据安全**：RAG 语料来自本地打包数据，问答不上传。
- **可移植**：整套 4 个文件可整体复制部署到任意静态托管（GitHub Pages / 对象存储 / 本地）。

## 七、本地运行

无需构建，任选其一：

1. **直接打开**：双击 `index.html`（部分浏览器对本地 `file://` 的 fetch 有限制，推荐方式 2）。
2. **本地静态服务**（推荐）：
   ```bash
   # 在仓库目录下
   python -m http.server 8000
   # 浏览器访问 http://localhost:8000
   ```
3. **GitHub Pages**：已自动托管于 https://tigeryoung555-ui.github.io/minhang-kuaiji/
