# 民用航空运输企业会计 · 智能教学平台

> 纯前端会计智能教学平台：**知识图谱 + 题库练习 + 案例教学 + 浏览器端 RAG 智能体 + 教学闭环（组卷/评阅/成绩/学情）**。
> 无需后端、可离线运行、可安装到桌面（PWA）。平台内置《民用航空运输企业会计》与《物流企业会计》两门课程。

🔗 **在线访问**：https://tigeryoung555-ui.github.io/minhang-kuaiji/

---

## 一、平台定位

面向**应用型本科会计类专业**的行业会计课程配套智能学习系统，支持「看图谱 → 学知识点 → 做练习 → 问智能体 → 看学情」的完整闭环。

- **零部署**：纯静态托管（GitHub Pages），打开网址即用，无需安装、无需服务器。
- **离线可用**：全部数据打包进前端 JS，RAG 推理与自动评阅在浏览器本地完成，断网也能练。
- **可安装**：支持 PWA，可添加到手机/电脑桌面，像原生 App 一样使用。
- **去学校化 · 通用化**：内容不绑定特定院校，可直接迁移到任意同类课程。

### 三条设计原则

1. **AI 辅助，不替代教师。** 智能体承担出题、评阅、统计等重复性工作，教师负责终审与高阶引导。
2. **不审不权威。** 所有 AI 生成内容一律标记 `pending`，经教师复核转 `approved` 后才计入正式考核，全程可追溯。
3. **知识可溯源。** 权威知识标注来源（A–G），AI 生成内容单独角标，学生可见「本题为 AI 生成待审」。

## 四、教学功能闭环（LA 已全链路打通）

```
题库（数据层）→ 试卷组合（按规则自动组卷）→ 自动评阅（客观判分 + 主观分步给分）→ 成绩生成（加权汇总 + 学情分析）
```

### 4.1 题库（数据层）

- **知识点编码体系**：`LA-章-K序号`（如 `LA-05-K07`），全库唯一，便于精准定位与薄弱点分析。
- 每题携带完整字段：题干、选项、答案、参考答案、分步评分量规（rubric）、解析、难度、建议分值、来源、复核状态。
- **扩库可复现**：新增题目只需放入 `la-chN-seed.json` 种子文件，构建脚本自动 glob 合并，重跑即可。

### 4.2 试卷组合（自动组卷）

三套模板，**seed 可复现**（同一 seed 生成同一份卷，便于复核与补考等值），并支持难度加权抽样与章节覆盖控制：

| 模板 | 题量 | 分值 | 时长 |
|---|---|---|---|
| 平时小测 | 10 | 20 | 20 min |
| 期中测验 | 22 | 54 | 50 min |
| 期末试卷 | 34 | 110 | 120 min |

### 4.3 自动评阅

- **客观题**：精确匹配，秒级判分，零人工。
- **主观题（计算 / 案例 / 分录 / 名词解释）**：按**分步评分量规（rubric）**给分——不仅看结果，还校验中间步骤（如折旧基数、成本分配率、借贷科目），**结果错误但方法正确仍给部分分**。
- 评阅后自动标记「未掌握」题目（客观题答错，或主观题得分率 < 60%）。

### 4.4 成绩生成

按 **平时 30% + 期中 20% + 期末 50%** 加权汇总，自动输出班级排名、成绩分布、平均分与薄弱知识点。

## 五、学生端功能

| 功能 | 说明 |
|---|---|
| **练习中心** | 按模块/章节、题型、难度筛选题目，支持自定义题量 |
| **错题本 · 间隔复习** | 答错可一键入册，按 **1 / 2 / 4 / 7 / 15 天** 间隔安排重练；答对自动进入下一周期，可标记「已掌握」 |
| **每日一题** | 每日推送并记录连续打卡天数 |
| **学习路线** | 按模块/章节展示题量与知识点分布，引导循序渐进 |
| **知识图谱** | 知识点及其关联关系可视化 |
| **智能助教** | 浏览器端 RAG 问答，基于课程知识库作答 |
| **模拟考试** | 试卷中心 → 智能评阅 → 成绩报表 完整闭环 |

> 错题本与「智能评阅」打通：评阅提交后支持**单题加入**或**一键批量把未掌握题加入错题本**。

| 功能 | 说明 |
|---|---|
| **教师驾驶舱** | 学生人数、平均掌握率、活跃率、完成率、平均成绩、风险学生等实时指标 |

## 七、技术架构

```
index.html            单页应用（UI + 全部交互逻辑，localStorage 持久化）
├── data.bundle.js    民航会计数据包（题库 / 知识点 / 案例 / 图谱）
├── la-data.js        物流企业会计数据包（500 题 / 59 知识点 / 组卷规则）
├── logistics-syllabus.js  物流企业会计教学大纲结构化数据
├── rag-client.js     浏览器端 RAG 检索客户端
├── manifest.webmanifest / icon.svg / sw.js   PWA（可安装 + 离线缓存）
└── .nojekyll         绕过 Jekyll，确保静态资源原样发布
```

- **纯前端**：无后端、无数据库，所有状态存于浏览器 `localStorage`，无需注册登录。
- **离线优先**：Service Worker 采用 network-first 策略，断网自动回落本地缓存。
- **本地推理**：RAG 检索与自动评阅均在浏览器完成，数据不出本机。

## 九、质量保障与复核机制

- AI 生成的题目初始状态为 `pending`，前端以角标提示「AI 待审」，**默认不进入练习筛选**（可手动勾选「包含待审题目」预览）。
- 教师通过「复核中心」逐条审核，导出 overlay 回写后转 `approved`。
- 复核记录独立于种子文件保存，**可回退**。
- 权威知识（教材 / 准则，来源 A–G）与 AI 生成内容在界面上区分展示。
